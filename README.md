# Unbound — issue tracker

Bug reports and ideas for **Unbound**, a space journey mod for Minecraft 26.3 (Fabric and NeoForge).
Mod page: https://modrinth.com/mod/unbound_mod

The mod is in **beta** and still in active development, so every report helps. Please:

- **search first** — maybe someone has already reported it; add a comment or a 👍 there instead of a new issue;
- **one issue — one problem or one idea**;
- write in **English or Russian**, whichever is easier for you;
- put the type in the title: `[Bug] …` or `[Idea] …`.

## Bug report

Copy this into a new issue and fill it in:

```markdown
**[Bug] Short description of the problem**

**Versions**
- Unbound: (e.g. 0.13.0)
- Loader: Fabric / NeoForge (and its version)
- Minecraft: 26.3
- Other mods: (list, or "none"; shader pack, Sodium/Iris/Embeddium if any)
- Singleplayer / multiplayer (dedicated server?)

**What happened**
What you saw, as exactly as you can.

**What you expected**
What should have happened instead.

**How to reproduce**
1. …
2. …
3. …
Does it happen every time?

**Where**
World / dimension, place, coordinates if you know them.

**Logs and screenshots**
- Crash or error: attach `logs/latest.log` (and the crash report from `crash-reports/` if there is one)
  as a file or via https://mclo.gs — please don't paste the whole log into the text.
- Screenshots or a short video help a lot for visual bugs.
```

## Feature request / idea

```markdown
**[Idea] Short title**

**What you'd like**
Describe the idea: a new thing, a mechanic, a change to something that exists.

**Why**
What problem it solves or what it would add to the game. What do you do now instead?

**Where it fits**
Which part of the mod it touches (a world, the journal, ships, machines, a boss…), and at what point of progression.

**Examples (optional)**
Sketches, screenshots, other games or mods that do something similar.
```

# Unbound — трекер багов и идей

Сообщения об ошибках и идеи для **Unbound** — космического мода для Minecraft 26.3 (Fabric и NeoForge).
Страница мода: https://modrinth.com/mod/unbound_mod

Мод в **бете** и активно разрабатывается, поэтому любое сообщение помогает. Пожалуйста:

- **сначала поищите** — возможно, об этом уже написали; лучше добавьте комментарий или 👍 там, чем новый issue;
- **один issue — одна проблема или одна идея**;
- пишите **по-русски или по-английски** — как удобнее;
- в заголовке укажите тип: `[Bug] …` или `[Idea] …`.

## Сообщение о баге

Скопируйте в новый issue и заполните:

```markdown
**[Bug] Коротко, в чём проблема**

**Версии**
- Unbound: (например, 0.13.0)
- Загрузчик: Fabric / NeoForge (и его версия)
- Minecraft: 26.3
- Другие моды: (список или «нет»; набор шейдеров, Sodium/Iris/Embeddium, если есть)
- Одиночная игра / сетевая (выделенный сервер?)

**Что произошло**
Что вы увидели — как можно точнее.

**Что ожидали**
Что должно было произойти.

**Как повторить**
1. …
2. …
3. …
Повторяется каждый раз?

**Где**
Мир / измерение, место, координаты, если знаете.

**Журналы и скриншоты**
- Вылет или ошибка: приложите `logs/latest.log` (и отчёт из `crash-reports/`, если он есть)
  файлом или через https://mclo.gs — пожалуйста, не вставляйте весь журнал в текст.
- Для визуальных багов очень помогают скриншоты или короткое видео.
```

## Предложение / идея

```markdown
**[Idea] Короткое название**

**Что хочется**
Опишите идею: новая вещь, механика, изменение того, что уже есть.

**Зачем**
Какую проблему решает или что добавит в игру. Как вы обходитесь сейчас?

**Куда это относится**
Какую часть мода затрагивает (мир, журнал, корабли, механизмы, босс…) и на каком этапе прохождения.

**Примеры (необязательно)**
Наброски, скриншоты, другие игры или моды, где есть похожее.
```
